로비화면에서 자신의 캐릭터를 누르면 개인페이지로 이동
개인페이지 화면 구성은 다음과 같음

0. 캐릭터 배치
화면 중앙에 배치

1. 현금 보유량
현금 보유량 현재 설정해둔 값 볼 수 있도록 현금 보유량 카드 화면 오른쪽에 배치
현금 보유량 카드 클릭 시 +/- 버튼을 통해 값 입력할 수 있는 팝업 화면 제공

2. 성공카드 뱃지
잠금 표시(아이콘 검은색으로 처리 후 중앙에 자물쇠 아이콘) --> 해제 시 아이콘 원본
클릭 시 성공카드 뱃지 해제 잠금 가능, 뱃지들은 모두 화면 오른쪽 위에 배치

3. 주식/부동산 보유 수량
현재 설정해둔 값들 볼 수 있는 요약 카드 화면 왼쪽에 배치 (주식 카드, 부동산 카드)

주식
a. 반도체·IT
b. 금융
c. 산업재·기계
d. 자동차·쇼핑
e. 바이오·헬스케어
f. 콘텐츠·플랫폼

부동산
a. 단독주택 가온개미
b. 단독주택 누리고양이
c. 다세대주택 다미원숭이
d. 다세대주택 마루수리
e. 아파트 초롱부엉이
f. 아파트 하늬여우

주식/부동산 카드 클릭 시 6종 각각 10개의 칸 +/- 버튼을 통해 채워넣거나 빼는 화면 팝업 형태로 등장

4. 직업 입력
이름과 아래 직업 화면 왼쪽에 배치
클릭 시 팝업 형태로 직업 선택 화면 등장
a. 경영·금융
b. 연구·기술
c. 보건·교육
d. 문화·콘텐츠
e. 서비스·판매
f. 생산·운송
