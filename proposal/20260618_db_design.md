프로젝트에 필요한 DB를 설계할거야. supabase를 사용해서 구현할 예정이고, 저장할 내용은 다음과 같아.

유저 테이블 : 유저ID, 이름, 캐릭터
팀 테이블 : 팀 ID, 팀 코드
주식가격 테이블 : 팀 ID, 반도체·IT, 금융, 산업재·기계, 자동차·쇼핑, 바이오·헬스케어, 콘텐츠·플랫폼 (팀 별 주식가격 설정)
부동산가격 테이블 : 팀 ID, 단독 가온개미, 단독 누리고양이, 다세대 다미원숭이, 다세대 마루수리, 아파트 초롱부엉이, 아파트 하늬여우 (팀 별 부동산가격 설정)
결과 테이블: 유저마다 주식, 부동산 보유수량, 현금, 성공카드 뱃지, 직업 저장하는 테이블

더 좋은 디자인이 있거나, 추가적으로 구현해야할 테이블이 있다면 제안해줘도 좋을 것 같아.
ex. 유저의 팀 참여 기록 테이블, 결과 테이블을 주식 테이블, 부동산 테이블, 현금 테이블, 성공카드 테이블, 직업 테이블로 나누는게 좋을지

지금 목표는 "결과 등록하기" 버튼을 통해 유저들이 기록한 정보들이 모두 DB에 저장되도록 만드는거야.
