# 경제적 잠재력 테스트 Figma 동기화 — 설계 스펙 (2026-09-21)

> 기반 문서: `proposal/20260921_test_figma_sync.md`
> 대상 파일: `src/pages/QuizIntro.jsx`, `QuizPlay.jsx`, `QuizResult.jsx` (+ 각 `.module.css`), `src/constants/quizData.js`, `src/index.css`
> 참고(선행 작업): `proposal/20260907_figma_responsive_sync_proposal.md` (onboarding-mode / `--sx`·`--sy` vscale 방식의 최초 정의), `2026-08-26-quiz-result-page-enhancements-design.md` (현재 결과 화면 구조)

## 1. 목적

퀴즈 3화면(시작화면·이름/성별/나이/질문·결과화면)을 새 Figma 시안(파일 `HpjLDHmo7XOCoFwnBJYJ6u`, node `2422:59454`/`2422:59543`/`2422:59848`/`2422:59623`/`2422:59791`/`2422:60939`)에 맞춰 다시 만든다. 두 축을 지킨다:

1. 화면별 컴포넌트의 위→아래 순서를 Figma와 동일하게 맞춘다.
2. 폰트/여백/버튼 크기의 비율이 화면 크기와 무관하게 항상 Figma와 같아 보이도록, Landing/NameInput/CharacterSelect/Team에 이미 적용된 `body.onboarding-mode` + `--sx`/`--sy` vscale 방식을 그대로 재사용한다.

## 2. 공통 인프라 — `quiz-mode` 폐기, `onboarding-mode`로 통합

세 페이지 모두 `useBodyClass('quiz-mode')` → `useBodyClass('onboarding-mode')`로 변경한다. `quiz-mode`를 쓰는 곳이 이 세 파일뿐이므로 `index.css`의 `body.quiz-mode` 관련 블록(및 관련 주석)은 완전히 삭제한다.

각 페이지의 `.page` 최상단에 (`NameInput.module.css` 패턴 그대로):

```css
.page {
  --sx: calc(100cqw / 834px);
  --sy: calc(100cqh / 1194px);
}
```

이후 모든 치수는 `clamp(최소값, calc(Figma실측값 * var(--sx|sy)), Figma실측값)` 형태로 쓴다. 가로 성격 값(좌우 여백·카드 너비·letter-spacing)은 `--sx`, 세로 성격 값(버튼/입력창 높이·상하 padding·세로 gap)은 `--sy`, 폰트 크기는 `min(--sx, --sy)`를 쓰는 기존 컨벤션을 그대로 따른다.

이 변경으로 퀴즈 화면은 더 이상 "기기 폭 그대로 자유 스크롤"이 아니라, 다른 온보딩 화면처럼 834×1194 카드 프레임 안에 들어간다.

## 3. 시작화면 (`QuizIntro`)

Figma 순서: 뒤로가기 → (중앙 정렬 블록) 제목 2줄 → 부제 2줄+강조줄 → 카드(메타 정보 행 + 시작 버튼) → 카드 아래 footer.

- 제목: "우리 아이" (검정) / "경제 잠재력 테스트" (`--blue-100`), 2줄.
- 부제: "우리 아이의 경제 컬러는 무엇일까요? / 아이와 가까운 모습을 선택해주세요" (회색) + "정답은 없습니다" (진한 글씨, 기존 `GUIDE_TEXT`와는 별개로 이 화면 전용 문구이므로 `quizData.js`에 새 상수로 추가).
- 카드(테두리 `--blue-75`) 안에 **신규**: 메타 정보 행 3개 — 질문 수(아이콘: assignment) / "약 3분" 고정 텍스트(아이콘: alarm) / "유형 분석" 고정 텍스트(아이콘: account_tree). 질문 수는 `QUESTIONS.length`로 동적 계산해 "N가지 질문" 형태로 렌더링한다(Figma의 "10가지 질문"은 예시 값이므로 문자 그대로 쓰지 않는다 — §6 참고).
- 카드 안, 메타 행 아래에 "테스트 시작하기" 버튼(기존 `startBtn` 유지, 스타일만 카드 내부로 이동).
- 카드 밖 하단에 **신규** footer: "© 2026 머니빌리지".
- 아이콘 3종(assignment/alarm/account_tree)은 Figma 에셋을 `get_design_context`가 내려준 URL에서 다운로드해 `src/assets` 또는 인라인 SVG로 커밋(7일 후 만료되는 임시 URL이므로 반드시 로컬에 저장).

## 4. 이름 / 성별 / 나이 (`QuizPlay` 앞 3단계)

세 화면 모두 구조는: 상단 진행률(퍼센트 텍스트 + 바) → (수직 중앙) 제목 → (이름/나이만) 부제 → 카드(입력 또는 선택지 + 다음 버튼).

### 4.1 진행률 계산 변경

Figma 실측 진행률(이름=1/10·10%, 성별=2/10·20%, 나이=3/10·30%, 질문-4=4/10·40%)을 분석한 결과, Figma의 플로우는 **"안내" 단계를 세지 않고 이름부터 1로 센다.** 총 단계 수는 "이름·성별·나이" 3개 + 질문 개수(`QUESTIONS.length`)다.

- 현재 코드: `TOTAL_STEPS = 4 + QUESTIONS.length` (안내 포함, 현재 값 10), `currentStepNumber`는 안내=1부터 시작.
- 변경 후: `TOTAL_STEPS = 3 + QUESTIONS.length` (현재 질문 6개 기준 9), 안내 화면은 진행률 표시에서 제외하고 이름=1부터 카운트.
- 안내 카드(STEP_GUIDE) 자체에는 진행률 바를 표시하지 않는다(§5).
- Figma에 적힌 "10"이라는 숫자와 "10가지 질문" 문구는 그 시안을 그릴 때 쓰인 예시값일 뿐이므로, 실제 구현은 항상 `QUESTIONS.length` 기반으로 동적 계산하고 표시 문구도 실제 개수를 따른다.

### 4.2 이름 화면

- 제목: "아이의 이름을 / 알려주세요" (2줄), 부제: "결과 화면에 표시됩니다".
- 카드: 라벨 "이름" + 텍스트 입력(placeholder "예: 이준서") + "다음" 버튼.
- `quizData.js`의 `NAME_LABEL`/`NAME_PLACEHOLDER` 값을 Figma 문구에 맞춰 갱신한다(레이블은 입력창 위 짧은 라벨 "이름"으로, 제목/부제는 페이지의 `title`/`subtitle`로 분리).

### 4.3 나이 화면

- 제목: "{아이 이름}는 몇 살인가요?" (이름 화면에서 입력받은 `childName`을 보간), 부제: "숫자를 입력해주세요".
- 카드: 라벨 "숫자" + number 입력(placeholder "예: 10") + "다음" 버튼.
- 마찬가지로 `AGE_LABEL`/`AGE_PLACEHOLDER`를 이 구조에 맞춰 갱신.

### 4.4 성별 화면 — 인터랙션 변경

- 제목: "성별을 / 선택해주세요" (부제 없음).
- 카드 안: 선택지 2개(ChoiceCard, 세로 스택) + "다음" 버튼.
- **동작 변경(승인됨)**: 옵션 클릭 → 해당 카드가 선택 상태(하이라이트 배경 `--blue-50` + 테두리 `--blue-75` + 체크마크, 텍스트는 `--blue-100`)로 바뀔 뿐 즉시 진행하지 않는다. 선택 후 "다음" 버튼을 눌러야 `STEP_AGE`로 진행한다. `handleGender`를 "선택만 하는 함수"와 "다음 버튼 클릭 시 진행하는 함수"로 분리해야 한다. 다음 버튼은 선택 전에는 비활성화(`disabled`).

## 5. 질문 카드 (`STEP_QUESTION`, 6문항 공용 템플릿)

- 순서: 진행률 → 질문 제목(`QUESTIONS[i].prompt`) → 부제 "아이와 가까운 모습을 골라주세요"(고정 문구, 신규 상수) → 카드(선택지 2개 + 다음 버튼).
- **동작 변경(승인됨)**: 성별 화면과 동일하게 select-then-confirm으로 변경. `handleAnswer`를 "선택 상태만 갱신" + "다음 버튼 클릭 시 답변 확정·다음 문항 또는 제출로 진행"으로 분리.
- 6개 문항 모두 동일 템플릿이므로 카드/선택지 컴포넌트는 성별 화면과 마크업을 공유할 수 있다(재사용 가능하면 작은 내부 컴포넌트로 추출 고려, 필수는 아님).

## 6. 안내 / 로딩 / 완료 / 에러 상태 (Figma 링크 없음)

이번 Figma 링크 범위에 없는 4개 상태는 질문 카드와 동일한 카드 스타일(테두리 `--blue-75`, `border-radius`, padding 등 새 비율)로 통일하고 새 834×1194 프레임 크기에 맞춰 조정한다.

- **안내(STEP_GUIDE)**: 카드 스타일만 새 프레임에 맞추고, §4.1에 따라 진행률 바는 표시하지 않는다(Figma 플로우에 없는 단계이므로).
- **분석중/완료(STEP_ANALYZING/STEP_DONE)**: 기존 스피너 레이아웃 유지, 온보딩 프레임 안에서 중앙 정렬되도록 크기만 조정.
- **에러(STEP_ERROR)**: 질문 카드와 동일한 스타일 재사용, 진행률 바는 마지막 진척도를 그대로 유지(기존 동작 유지).

## 7. 결과 화면 (`QuizResult`) — 구조 변경

새 순서(Figma 기준): 히어로(배경 이미지, 크롭+하단 페이드) → 흰 카드(위쪽만 둥근 모서리, 그림자, 히어로 위로 살짝 겹침) 안에 헤더 배지 → 그룹명 → 태그라인 → 설명 박스 → **대표 동물(신규 섹션)** → **핵심 가치(그리드로 재구성)** → 더 알아보기 → 공유하기 → 다시 하기 버튼.

### 7.1 히어로 이미지

- 배경 이미지 파일 자체는 이미 `public/groups/*.png`에 있음(교체 불필요, 이번 세션에서 확인됨). 크롭/페이드 처리만 새로 추가한다.
- 컨테이너를 고정 비율 높이(834×1194 기준 360px → `--sy`로 스케일)로 만들고, 이미지는 그 안에서 `object-fit: cover` + 상단 기준 정렬(Figma의 `top: -1.83%` 오프셋에 해당)로 크롭한다. 기존 `line-height:0; width:100%; height:auto`(원본 비율 그대로 흘려보내는 방식)를 대체한다.
- 히어로 하단, 카드 경계와 만나는 지점에 흰색 그라디언트 페이드(투명→흰색)를 얹어 카드 배경과 자연스럽게 이어지게 한다.
- 카드는 기존처럼 음수 `margin-top`으로 히어로 위에 겹치되, 위쪽 모서리만 `border-radius`를 주고 `box-shadow`를 추가한다(Figma: `0 -4px 16px rgba(0,0,0,0.08)`).

### 7.2 헤더 배지 / 그룹명 / 태그라인

- "우리 아이의 경제적 잠재력은" 문구를 그룹 컬러의 옅은 배경 pill(`border-radius: 999px`)로 감싼다(현재는 맨 텍스트).
- 그룹명(`result.result_group`, 예: "Orange Group")은 그룹 컬러로 그대로 유지.
- 태그라인: 현재 `[{group.tagline}]`처럼 대괄호로 감싸고 그룹 컬러를 칠하는데, Figma는 대괄호 없이 회색(`--ink-2`)이다 — 대괄호 제거 + 색상을 `--ink-2`로 변경.

### 7.3 설명 박스

현재 "✅ {description}" 평문을 그룹 컬러의 옅은 배경 + 테두리가 있는 박스로 바꾸고, 이모지 "✅" 대신 체크박스 SVG 아이콘을 쓴다(Figma `check_box` 아이콘 에셋을 다운로드해 커밋).

### 7.4 대표 동물 (신규 섹션)

현재 `{group.animals.join(' · ')}`로 텍스트 나열만 하던 것을, 동물마다 원형 컬러 배지(옅은 그룹 컬러 배경) 안에 이모지 + 아래에 이름 캡션을 두는 가로 리스트로 바꾼다.

- `quizData.js`의 각 그룹 `animals` 배열은 지금 이름 문자열만 담고 있으므로(`['개미', '부엉이', ...]`), 이모지를 붙일 수 있도록 `{ name, emoji }` 객체 배열로 바꾸거나, 별도의 이름→이모지 매핑 테이블을 추가한다. 4개 그룹 16종 전체(판다🐼·캥거루🦘·고양이🐱·펭귄🐧·강아지🐶·여우🦊·원숭이🐵·호랑이🐯·개미🐜·부엉이🦉·다람쥐🐿️·수달🦦·독수리🦅·돌고래🐬·사자🦁·코끼리🐘) 매핑을 채운다.

### 7.5 핵심 가치 (그리드로 재구성)

현재 축 2개(오늘/내일, 안전/모험)를 밑줄 텍스트 인라인 행으로 보여주는데, Figma는 "핵심 가치" 레이블 아래 2×2 그리드의 카드 칩으로 보여준다. 활성 축(현재 `isTodayTomorrowLeftActive`/`isSafetyAdventureLeftActive`로 계산 중)은 그룹 컬러 배경+테두리로 강조, 비활성은 흰 배경+회색 테두리. **판정 로직은 그대로 재사용하고 마크업/스타일만 그리드로 교체한다.**

### 7.6 더 알아보기 / 공유하기 / 다시 하기

- 더 알아보기·공유하기 섹션은 구조 동일, 카드 폭/패딩만 새 비율(`--sx`/`--sy`)로 조정.
- "다시 하기" 버튼: 현재 `navBtnStyle`(그룹 컬러)을 쓰는데, Figma는 그룹과 무관하게 항상 `--blue-100`이다 — 그룹 컬러 오버라이드를 제거하고 고정 파란색으로 변경.

## 8. 데이터 변경 (`quizData.js`)

- 신규 상수: 시작화면 부제/강조줄 문구, 질문 카드 공통 부제("아이와 가까운 모습을 골라주세요"), 안내/에러 화면에 쓰이던 문구는 유지.
- `NAME_LABEL`/`AGE_LABEL`을 "입력창 위 짧은 라벨"과 "화면 제목" 두 역할로 분리(현재는 라벨 하나가 제목 역할까지 겸함).
- `RESULT_GROUPS[].animals`를 이모지 매핑이 가능한 구조로 확장(§7.4).
- 진행률 분모: `QUESTIONS.length + 3`로 계산하는 헬퍼(또는 상수)를 추가해 `QuizIntro`의 메타 정보 행과 `QuizPlay`의 진행률 표시가 같은 값을 참조하게 한다.
