# 경력기술서 초안 — 담당업무 / 성과

> 소재: "머니빌리지" 경제교육 보드게임 웹서비스 (1인 기획·개발, React + Express·Socket.io + Supabase)
> 근거 문서: proposal/, docs/superpowers/specs/ (2026.06.11 ~ 2026.09.10 설계 문서 기준), test-reports/20260831_qa_result.md, server/*.test.js

실제 프로젝트 산출물(설계 제안서, 코드, 테스트 파일, QA 리포트)을 근거로 작성했습니다. 지원 양식의 글자 수 제한에 맞춰 아래 5개 항목 중 2~3개를 선택하거나 병합해서 사용하시면 됩니다.

---

### 1. 풀스택 개발

**담당업무**: 경제교육 보드게임 웹서비스 '머니빌리지' 기획부터 프론트엔드(React)·백엔드(Node.js/Express·Socket.io)·DB(Supabase) 설계까지 전 영역 1인 개발

**성과**: 약 3개월간 기획-설계-개발-배포 전 주기를 단독 수행하여 실제 수업 현장에 투입 가능한 수준의 풀스택 서비스 완성에 기여

---

### 2. 실시간 멀티플레이어 동기화

**담당업무**: 최대 4인이 동시 참여하는 팀 게임을 위한 Socket.io 기반 실시간 동기화 기능(팀 로비, 자산 입력 현황, 가격 변경, 강퇴, 관리자 관전) 설계 및 구현

**성과**: 다중 클라이언트 간 실시간 상태 동기화 구조를 구축하여 별도 새로고침 없이 팀원 현황·입력 진행률이 즉시 반영되는 멀티플레이어 환경 확보

---

### 3. 관리자(교사)용 운영 시스템

**담당업무**: QR코드 기반 수업 입장 흐름 및 교사용 학급·팀 관리 대시보드(그리드/테이블 뷰, 일괄 등록, 실시간 관전) 개발

**성과**: 교사 1인이 QR 배포만으로 다수 학급·팀을 동시에 운영할 수 있는 관리 체계를 구축하여 수업 운영 인력 부담 경감에 기여

---

### 4. 디자인-구현 정합성 문제 해결 (Figma 반응형 동기화)

**담당업무**: Figma 디자인 시안과 반응형 구현 결과물 간 불일치 문제에 대해 좌표·색상·폰트 수치 비교를 통한 근본 원인 분석 및 반응형 로직 재설계

**성과**: 두 차례 반복되던 디자인 불일치 문제의 원인(화면 비율 불일치, 요소별 축소 비율 상이)을 데이터 기반으로 규명하여 전체 화면을 Figma 시안과 일치하도록 개선

---

### 5. 테스트 자동화 및 QA

**담당업무**: Vitest 기반 프론트엔드·백엔드 자동화 테스트 및 AI 브라우저 자동화 기반 다중 페르소나(학생·학부모·교사) QA 시나리오 설계·실행

**성과**: 백엔드 API 135개 이상의 테스트 케이스와 전 페이지 단위 프론트엔드 테스트를 구축하고, 회귀 테스트 체크리스트 54개 항목 중 87%(47건) 정상 동작을 확인하며 치명적 버그 2건을 배포 전 조기 발견
