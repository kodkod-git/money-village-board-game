## 5. 발견된 이슈 목록

### ISSUE-1 — 사용자 피드백에 브라우저 네이티브 `alert()` 사용 (심각도: 높음)

| 항목 | 내용 |
|---|---|
| 역할 | 학생 / 선생님 |
| 화면/기능 | 초대코드 참여 실패, 호스트 퇴장 시 남은 팀원, 관리자 방 생성 실패, 관리자 "전체 등록" 결과 안내 |
| 재현 경로 | (예) 홈→시작하기→존재하지 않는 코드 `ZZ9XQ2` 입력→이름/캐릭터→시작 |
| 기대 | 앱 내부 커스텀 모달/토스트로 안내 |
| 실제 | `alert()` 호출로 렌더러 블로킹. 자동화 기준 페이지 응답 불능, 페이지 이동해야 회복. 앱의 나머지 UI는 커스텀 모달(ConfirmDialog, LeaveConfirmModal 등)을 쓰는데 이 8곳만 불일치 |
| 코드 위치 | `src/pages/Lobby.jsx:75`, `src/pages/Team.jsx:113`, `src/pages/AdminClassDashboard.jsx:74,79,113,117,118,121` |
| 부가 | `src/pages/TeamCodeInput.jsx:11-13` — 코드 입력 화면이 방 존재 여부를 전혀 검증하지 않고 `/join`으로 이동. 검증을 이 단계로 앞당기면 alert 경로 자체를 줄일 수 있음 |

### ISSUE-2 — 학급 없이 진입한 학생은 방을 만들 수 없음 (심각도: 중간, 사양 확인 필요)

홈 "시작하기" → `/join-code`는 코드 입력 UI만 존재. `classId` 없이 `/lobby` 도달 시에도 코드 입력 뷰만 렌더되고(`Lobby.jsx:105-136`) "방 만들기" 버튼은 `classId`가 있을 때만 표시. 학생이 스스로 방을 만들려면 교사 학급 QR/링크(`classId` 포함)로 진입해야만 함. 의도된 설계일 수 있으나 문서 3.1.4의 정식 플로우와 불일치. 확인 필요.

### ISSUE-3 — 마지막 팀원 완료 시 게임이 자동 제출되지 않음 (심각도: 중간, 문서-구현 상이)

문서 4.5 기대와 달리 학생 측 자동 제출 트리거가 없음. 제출은 관리자의 관전 팝업 "결과 등록"(`AdminSpectateModal.jsx:100`) 또는 대시보드 "전체 등록"(`AdminClassDashboard.jsx:110`)에서만 발생. 설계 의도라면 문서를, 버그라면 `IndividualPage.handleComplete`에 전원 완료 시 submit 호출을 추가해야 함.

### ISSUE-4 — 관전 팝업이 "읽기 전용"이 아님 (심각도: 낮음, 문서-구현 상이)

문서 3.3.4는 관전 팝업이 "참가 불가, 관전만" 읽기 전용 로비 화면이길 기대하나, 실제 `AdminSpectateModal`은 플레이어별 수정/퇴장, 팀 가격설정/삭제/결과등록이 가능한 관리 패널. 기능상 문제는 아니며 문서 갱신이 필요해 보임.

### ISSUE-5 — 강퇴된 학생에게 안내 없음 (심각도: 낮음)

호스트가 팀원을 강퇴하면 해당 탭은 조용히 `/lobby`로 이동만 함(`Team.jsx:97-108` `you-were-kicked` 핸들러). "강퇴되었습니다" 등 안내 토스트가 없어 학생이 왜 튕겨났는지 알 수 없음.

### ISSUE-6 — `/lobby` 진입 후 렌더러 응답 지연 (심각도: 낮음, 재현 불안정)

`classId`가 있는 `/lobby` 진입 후 스크린샷/스크립트 주입이 지속적으로 타임아웃되다가 페이지 이동 시 회복되는 현상이 세션 내내 반복됨. 자동화 환경(소켓 연결 다수 + dev 모드 재렌더) 문제일 가능성이 높으나, `/lobby`가 다른 화면보다 유독 심했음. 실제 저사양 모바일에서의 체감 성능 확인 권장.

### ISSUE-7 — `/result/:sessionId` 기본 스코프가 "전체" (심각도: 낮음)

게임 직후 이동하는 결과 페이지가 자기 팀(세션) 순위가 아닌 전체 랭킹을 먼저 보여줌. "팀" 탭을 눌러야 Jiho/Minseo만 표시됨. 결과 페이지는 팀 스코프를 기본값으로 하는 편이 자연스러움.

### 관찰 사항 (이슈 아님)

- **캐릭터 선택 / 자산 입력 단계의 그리드가 데스크톱 폭에서 우측 정렬**되어 카드 왼쪽에 큰 빈 공간 발생 (모바일에서는 정상으로 보임). `CharacterSelect`, `IndividualPage` 등 공통.
- **팀 화면 h1이 "팀 만들기"** — 이미 방을 만든 뒤의 화면 제목으로는 혼동 소지(문서는 "팀 화면"으로 지칭). `Team.jsx:157`.
- 관리자 로그인 빈 값 에러 문구 "username과 password가 필요합니다" — 교사 대상 한국어 UI에 영어 필드명 노출.
- 퀴즈 소개 화면·플레이 화면에 우측 세로 경계선이 살짝 보임(컨테이너 배경 차이).
